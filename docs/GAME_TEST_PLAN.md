# Короткий игровой тест владельца

До этого теста BlackBox в основной модпак не установлен. Агент не запускал мир. Первую проверку проводить в отдельном временном соло-сохранении; основной мир не загружать ради проверки кандидата.

1. Закрыть игру. Установить мод по WORKSHOP_INSTALL.md, включить его вместе с ZombieBuddy и индивидуально одобрить JAR.
2. Запустить меню, подождать 10 секунд. Проверить `[PZBlackBox] Recorder started` и новую папку `Zomboid/BlackBox/sessions/...`.
3. Создать отдельную временную соло-игру. Постойте 20 секунд, пройдите пешком 30 секунд, откройте/закройте инвентарь. Никаких обязательных иных модов нет.
4. Если тестовый мир уже содержит машину, сравнить короткий маршрут водителем/пассажиром с другом. Для контролируемого теста основной мир не нужен. Не создавать лишний контент в основном сохранении.
5. При проблеме вызвать штатно из Lua-консоли `PZBlackBox.markProblem()`. Постоянно следить за регистратором не требуется: длинные кадры/операции и новые исключения создают триггеры автоматически.
6. Через 15 секунд после проблемы: `PZBlackBox.exportSession()`. Дождаться `safe-export.zip` в папке текущей сессии. Либо выйти штатно: экспорт запускается автоматически с ограничением времени.
7. Передать safe-export.zip. При неудачной упаковке исходные JSONL остаются в папке. Raw JFR не отправлять, пока не проверена приватность.

Реальная проверка должна подтвердить: нет ошибок трансформаций BlackBox; Lua/game context не отключились; кадры/ошибки/чанки появляются при реальной активности; пауза и меню помечены правильно; нет заметного ухудшения. Отсутствие ошибок в меню не доказывает прохождение остальных сценариев.

Для оценки overhead нужны две сопоставимые короткие сессии на тестовом мире с одинаковым маршрутом/модами/настройками: с BlackBox и без него. Зафиксировать FPS/frametime доступным штатным способом. Сравнивать медиану и распределение, а не разные сцены. DEEP максимум 60 секунд, по явной команде; затем автоматическое возвращение в прежний режим. Существующие функции Viewpoint сохраняются; BlackBox не меняет камеру или графику.

Host отдельно: сначала проверить реальное наличие ZombieBuddy в серверной JVM. Без него не пытаться трактовать клиентский JSONL как серверный. Автоматически изменять Host launcher не требуется и не разрешено установщиком BlackBox.
