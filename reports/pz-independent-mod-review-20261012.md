# Независимый отбор модов Project Zomboid для pzhardcore — 12 октября 2026

## Методология и ограничения

- Основа: два предоставленных файла `pz-collection-review.json` и `.md`; 293 уникальных пакета коллекций, из них 37 уже в Host и 256 отсутствуют.
- Отбор заново проведён с учетом Build 42.21, Project Viewpoint alpha 0.1.6, игры через встроенный Host, мобильного выживания 2–4 человек, ограниченной вместимости машин, дефицита ресурсов и сохранения модпаковых функций.
- Дополнительно проверены авторские Steam-страницы ряда важных модов. Это не полный кодовый или игровой аудит каждого из 256 пакетов: для большинства отсутствуют локальные исходники и тесты MP.
- **Ни один пакет не установлен и настройки не изменены.** Оценка «Волна 1» означает приоритет для теста, а не гарантированную совместимость.

## Наиболее важные уточнения относительно отчёта Codex

1. **Nested Containers (3410947298)**: на странице автор указывает, что MP не работает; есть жалобы на зависание переноса. Для Host исключить до подтверждённого исправления.
2. **Living Props (3816442251)**: автор заявляет чисто клиентский режим; установка на Host не требуется. Уже есть жалобы на замещение моделей sour_kisel и KK's Shelves. Проверять последним в порядке загрузки и переключением конкретных моделей.
3. **Project Cook (3490188370)**: автор прямо заявляет B42.21/SP/MP, умеет учитывать соседние контейнеры, NeatUI Framework уже есть. Приоритет высокий, но тест всё равно нужен.
4. **Has Been Read (2544353492)** и **Tidy Up Meister (2769706949)**: Build 42 уже включает часть функций, поэтому вначале проверь, чего не хватает без этих модов.
5. **Advanced Throwables (3813194971)**: адаптирован под Viewpoint 0.1.6, имеет Java-компонент на клиенте и Lua-проверки на сервере; проверить клавишу G, броски в MP, реакцию зомби, урон и логи.
6. **Rain Cleans Blood (2956146279)**: автор заявляет очистку одежды и машин дождём в MP без изменения существующего мира; отдельный тест с Blood FX.

## Очерёдность

**Волна 1:** чистый интерфейс/подсветки/информация и Project Cook; устанавливать малыми партиями в копию Host.
**Волна 2:** игровые взаимодействия (броски, разборка, предметы, визуальные модели), отдельно каждый конфликтный компонент и измерение FPS.
**Только по согласию:** изменения сложности, добычи, веса, прокачки, физики и новый контент.
**Автомобили:** из 69 добавлять лишь конкретные модели, чтобы не раздувать парк и зависимостями не сломать текущий мир.

## После отбора: как ставить безопасно

1. Снять резервную копию конфигураций Host, настроек клиента и мира. Все тесты проводить на копии мира/отдельном тестовом Host, не на основном сохранении.
2. Для модов UI и 3D сначала тест на клиенте, где это поддерживается автором. Не добавлять клиентский мод в Host без необходимости.
3. Для серверных модов не доверять одному только статусу загрузки: проверять взаимодействия и повторный старт/сохранение, особенно контейнеры, автомобили, модовую электронику и броски.
4. Проверить точный Mod ID, Workshop ID, зависимости и порядок. Не включать все модули одного Workshop-пакета автоматически.
5. Разделять производительность/память клиента и Host. Не включать шейдерные, HUD и анимационные замены одновременно.
6. После серии тестов собрать свежий `console.txt`, `coop-console.txt`/логи Host, сравнить Lua/Java ошибки и беззвучные отключения функций.
