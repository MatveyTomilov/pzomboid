Конкретная причина пассажирской тряски и вина PZ_Optimization пока не доказаны. Старые локальные Java-копии отличаются от Steam/Host, но их участие в runtime не установлено.

Пароли, токены, IP, SteamID и имена игроков скрыты. Сейвы, базы игроков, полные исходные логи, JAR и файлы модов не публикуются. ZIP содержит шесть документов и evidence; этот README служит индексом репозитория.
