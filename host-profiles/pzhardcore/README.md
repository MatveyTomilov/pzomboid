# Перенос настроек pzhardcore

Скопированы фактические настройки встроенного **Host через меню игры**. Dedicated Server не требуется.

В комплекте:

- `Server/pzhardcore.ini` — параметры сервера, точные `Mods=` и `WorkshopItems=`;
- `Server/pzhardcore_SandboxVars.lua` — сложность, зомби, лут, NPC и настройки модов;
- `Server/pzhardcore_spawnpoints.lua` и `Server/pzhardcore_spawnregions.lua` — точки и регионы появления;
- `Mods.txt`, `WorkshopItems.txt`, `mods-manifest.json` — выбранные модули, пакеты, названия и зависимости;
- `profile.json` — версия игры, число модов и особенности переноса;
- `SHA256SUMS.txt` — контрольные суммы переносимых файлов;
- `INSTALL_FOR_AI.md` — порядок установки на другом ПК.

`pzhardcore-settings-20261014.zip` содержит **только настройки, списки и инструкции**. Мир, персонажи, базы игроков, логи, Workshop-архивы, JAR и файлы игры отсутствуют.

Отдельно приложен наш локальный мод `BushmasterAmbulanceCapacity300.zip` и его исходная папка `local-dependency/BushmasterAmbulanceCapacity300`. Он уже включён в текущем Host, но у него нет Workshop ID. Без его установки точный состав Host не восстановится. Это существующий пользовательский патч, его код при экспорте не менялся. Требуются исходный Bushmaster `2897390033` и его зависимости из списка. Этот локальный мод нужно установить также каждому подключающемуся игроку; Steam его автоматически не скачает.

Из экспортного INI очищен непустой `Password`. Пустые поля секретов остаются пустыми. Строки `ResetID` и `ServerPlayerID`, привязывающие профиль к прежнему миру/персонажам, исключены. Новый ПК должен получить свои идентификаторы. Все остальные значения INI сохранены. Sandbox и оба Lua-файла спавна побайтно совпадают с исходниками.

В исходном интерфейсе Host выделено 7168 MiB памяти. Это справочное значение, а не обязательное требование к любому ПК; память задаётся отдельно в меню «Хост». Графика, кнопки, клиентские JVM-параметры и модификации файлов игры в этот комплект не входят.

Workshop получает текущие версии авторов, поэтому этот профиль фиксирует **состав и настройки**, но не гарантирует сохранение версий модов. Совместимость будущих обновлений и игровой запуск на другом ПК при экспорте не проверялись.

Проверка экспорта: 235 уникальных Mod ID, 211 уникальных Workshop ID; идентификаторы сверены с установленными `mod.info`; обязательные `require` входят в выбранный набор. Конфигурация и сохранения исходного ПК не изменялись.
