# Задание ИИ на другом Windows-ПК

Восстанови настройки встроенного Host `pzhardcore` из этого профиля. Не создавай Dedicated Server и не переноси сохранения. Источник истины — файлы в `Server/`, а не старые отчёты и не список всех подписок пользователя.

## 1. Найти установленную среду

Определи Steam, все Steam Library, установленный Project Zomboid и фактический каталог данных Zomboid. Обычно данные находятся в `%USERPROFILE%\Zomboid`; если запуск использует `-cachedir`, применяй фактический каталог. Не предполагай совпадение диска, имени пользователя или путей с исходным ПК.

Исходная версия игры — 42.21.0. Не переключай ветку и не обновляй/откатывай существующую игру без решения владельца при несовпадении версии. Сначала сообщи о несовпадении.

Проверь, что игра и её Host остановлены. Не завершай процессы самостоятельно. Если существующий `pzhardcore` уже используется, сначала сохрани его конфигурацию в отдельную резервную папку. Не удаляй и не сбрасывай существующий мир. Уточни у владельца, если он хочет новый мир, а имя `pzhardcore` уже привязано к имеющемуся сохранению: копирование настроек само по себе не сбрасывает прогресс.

## 2. Получить моды

Используй `WorkshopItems.txt` — 211 одобренных пакетов. Загружай их через официальный Steam Workshop и проверяй наличие файлов. Ссылки и сопоставление пакетов с модулями указаны в `mods-manifest.json`.

После скачивания сверяй реальные `mod.info` с `Mods.txt`. Сохраняй Mod ID, обратные слеши, порядок и выбор модулей из `Mods=`. Не включай все подпакеты автоматически: в наборе специально отключены некоторые варианты машин и дополнения. Не добавляй другие подписки пользователя. Если пакет исчез, Mod ID переименован или обязательная зависимость недоступна, перечисли проблему и останови затронутую часть; не заменяй её наугад и не изменяй остальной набор ради обхода ошибки.

Установи существующий локальный мод из `BushmasterAmbulanceCapacity300.zip`:

`<каталог данных Zomboid>\mods\BushmasterAmbulanceCapacity300\42\mod.info`

Сохрани также папку `common` и остальные файлы архива. В `Mods=` он уже есть; второй экземпляр и Workshop ID для него добавлять не нужно. Каждый друг должен распаковать одинаковый локальный мод в свой каталог `Zomboid\mods`. Проверку целостности сервера не отключать.

Project Viewpoint и ZombieBuddy входят в выбранный набор. У Java-модов загрузка Workshop-файлов не всегда завершает установку: изучи инструкции **скачанной версии ZombieBuddy** и её загрузчика и выполни документированные необходимые шаги на новом ПК. Не копируй DLL/JAR/параметры JVM/старые локальные копии с исходного ПК. Не добавляй экспериментальные оптимизации. Если требования новой версии не совпадают с исходными, объясни конкретное ограничение до изменений файлов игры. Не считай регистрацию Mod ID доказательством загрузки Java-компонентов.

## 3. Применить настройки

Проверь контрольные суммы по `SHA256SUMS.txt`, затем скопируй четыре файла из `Server/` в `<каталог данных Zomboid>\Server\`. Создай этот каталог, если его нет.

Не копируй ничего в `Saves`, `db` или каталоги игроков. Не меняй Sandbox, сложность, NPC, лут, зомби, список модов, античит и остальные параметры. Не выполняй сброс мира. Не импортируй `ResetID` и `ServerPlayerID` из какого-либо старого отчёта.

В экспортном INI `Password=` пустой: владелец должен задать новый пароль перед открытием доступа к серверу. Не публикуй его в Git и не восстанавливай исходный пароль по догадке. `Public=false` и остальные настройки доступа сохранены.

Для выбора через меню игры достаточно профиля `pzhardcore` в каталоге `Server`. Не перезаписывай глобальные настройки клиента и его список модов только ради работы Host: требуемые серверные моды выбираются профилем и синхронизируются при подключении. Клиентские инструменты владельца и графические настройки в снимок не входят.

При желании владельца установи память Host через меню: исходное значение 7 GB (7168 MiB). Сначала учти доступную RAM нового ПК и одновременную работу клиента. Не меняй Windows, файл подкачки и клиентскую JVM ради копирования настроек.

## 4. Базовая проверка и передача владельцу

Проверь наличие выбранных пакетов, точные Mod ID, `require`, отсутствие дубликатов и совпадение списков с профилем. Исходный набор: **235 Mod ID / 211 Workshop ID**, включая один локальный мод без Workshop ID. Не подгоняй числа при недоступном контенте; сообщи точное отклонение.

Не запускай и не загружай основной мир автоматически. Передай владельцу результат установки и ограничения. Первый игровой запуск и проверка подключения друзей — отдельная стадия по разрешению владельца. Игра должна сама сформировать новый мир и его идентификаторы при разрешённом первом запуске; этот комплект мира не содержит.

Другие игроки скачивают выбранные Workshop-пакеты при подключении, если Steam и серверная загрузка работают. Локальный Bushmaster-патч и требуемый Java-загрузчик устанавливаются отдельно. Не обещай автоматическую установку этих компонентов через `WorkshopItems=`.

Откат переноса: остановить игру/Host и вернуть только четыре конфигурационных файла из сделанной на новом ПК резервной копии. Если этих файлов ранее не было, убрать только вновь скопированные файлы после проверки точных путей. Сохранения и базы игроков не трогать. Локальный Bushmaster-патч после игры не удалять вслепую: контейнеры сначала должны быть разгружены до штатной вместимости.
