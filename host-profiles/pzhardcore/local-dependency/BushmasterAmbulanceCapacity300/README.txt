Bushmaster Ambulance — Capacity 300

Только автомобиль Base.97bushAmbulance из '97 ADI Bushmaster (Workshop 2897390033).
Все его существующие предметные контейнеры получают базовую вместимость 300:
сиденья, бардачок, багажник, медицинский шкаф, боковые и верхние контейнеры.
Занятое сиденье сохраняет базовую вместимость 300. Черты Organized/Disorganized
по-прежнему изменяют эффективную вместимость стандартным способом игры.
Топливные/жидкостные баки, другие варианты Bushmaster и другие машины не меняются.
Мод не добавляет отсутствующие детали и не снимает ограничения доступа к ним.
Обновление вместимости происходит при загрузке игры и каждые 30 игровых тиков.

Установка для владельца Host и каждого друга:
1. Полностью закройте игру.
2. Распакуйте папку BushmasterAmbulanceCapacity300 в C:\Users\ВАШЕ_ИМЯ\Zomboid\mods.
   Итоговый путь: Zomboid\mods\BushmasterAmbulanceCapacity300\42\mod.info.
3. Оригинальный мод Bushmaster и его обязательная damnlib должны быть установлены.
4. Владелец в настройках Host pzhardcore, раздел Моды, включает
   Bushmaster Ambulance - Capacity 300 (Mod ID BushmasterAmbulanceCapacity300).
   Остальные Mod ID и все настройки песочницы оставляет прежними.
5. Каждый игрок включает локальный мод у себя; перезапустите Host и подключайтесь.

У локального архива нет Workshop ID: автоматически скачивать его через Workshop
сервер не сможет. Все игроки должны распаковать одинаковый архив.
Не выключайте проверку файлов/целостности сервера.

Исходные файлы Workshop, конфигурации Host и сохранения этим архивом не изменены.
Работает также с уже существующими загруженными машинами; предметы не удаляются.
При откате сначала разгрузите контейнеры до штатной вместимости, затем выключите
только этот addon у всех игроков и перезапустите игру/Host.

Проверка: Lua проверяется компилятором Kahlua из установленной игры и модельными
тестами области действия. Настоящий игровой/сетевой тест не выполнен.
Version 2.0: corrected B42 Set iteration (iterator, hasNext, next).
Verified with real Java HashSet and the installed Kahlua runtime on Java 25.
Game-world and multiplayer functionality still require an actual game test.
