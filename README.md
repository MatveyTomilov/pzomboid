# Project Zomboid — сюжетная кампания Extraction Mode

**Статус:** предпроектное исследование. Квесты, баланс и интеграция ещё не реализованы.

Новый проект: самостоятельная сюжетная кампания для Project Zomboid Build 42 с использованием механик **Extraction Mode**, **Tarkov Traders** и совместимых дополнений. Цель — связная история, исследование, развитие убежища, отношения с торговцами, разнообразные игровые задачи и ощутимые награды. Количество заданий определяется качеством и доступными механиками, а не фиксируется на 100.

## Рабочая задача и связь агентов

**[Issue #1 — аудит механик, наград, модов и баланса](https://github.com/MatveyTomilov/pzomboid/issues/1)** — текущая точка входа для Codex и ChatGPT.

- **ChatGPT** отвечает за структуру кампании, лор, характеры, диалоги и пользовательский игровой опыт; избегает раскрытия сюжетных секретов игроку.
- **Codex** проверяет фактические API/исходники модов, совместимость, систему наград и экономику, выполнимость, серверную авторитетность и кооператив. Результаты оставляет в Issue/PR с уровнем подтверждения.
- **Владелец** организует доступ Codex к репозиторию и проверяет игровое поведение на Host. Не требуется самостоятельно придумывать квесты или награды.

## Правила для новой разработки

1. Сначала аудит механик убежища, персонажей, экономики, торговли, инвентаря, модового лута и прогрессии; затем сюжетный дизайн и реализация аддона.
2. Не выдавать задуманные игровые механики за реализованные. Для ID предметов, координат и API требуются доказательства из исходного кода; проверка игры — отдельный уровень.
3. Новая сборка Extraction Mode ещё **не подтверждена** содержимым репозитория. Старые конфиги Host и списки модов не использовать как актуальный источник.
4. Не менять существующие сейвы, установленную сборку, профиль Host и Workshop без отдельного разрешения. Не подключать платные сервисы без согласия.
5. Для изменений использовать отдельные task-ветки и PR; `main` содержит только актуальную информацию по этому проекту.

## Старые материалы

Отчёты, ранее размещавшиеся в `main`, удалены из **текущего дерева**, но доступны в истории Git. Ветви `configs/pzhardcore-20261014`, `reports/performance-20261014` и `feature/pz-blackbox` — исторические самостоятельные работы, **не часть новой кампании**; их данные не считаются актуальными, пока не подтверждены.

Новая реализация не должна наследовать старые настройки, моды или патчи автоматически.
