# PZ BlackBox

Фоновый диагностический мод для **Project Zomboid 42.21 и ZombieBuddy 2.3.4**. Записывает технические наблюдения для последующего анализа: кадры, границы Lua-вызовов, ошибки, JVM/JFR, зомби, чанки и ресурсы. Не оптимизирует игру, не меняет механику и не отправляет данные в сеть.

Это кандидат для игрового теста. Работа в реальном мире, совместимость со всеми другими Java-патчами и процент накладных расходов пока не подтверждены. Синтетические тесты не являются игровой сессией.

## Сборка

Java 25 требуется для исполнения и проверки API установленной игры. Исходники BlackBox компилируются с target 21; они совместимы с Java 25. Можно использовать уже установленный JRE игры и ECJ 3.43.0, без установки JDK и без изменения системного JAVA_HOME.

```powershell
./blackbox/build.ps1 -GameDir 'E:\SteamLibrary\steamapps\common\ProjectZomboid' `
  -GradleHome 'путь\gradle-9.1.0' -EcjJar 'путь\ecj-3.43.0.jar'
```

Скрипт не скачивает инструменты, не запускает игру и не устанавливает мод. Compile-only `projectzomboid.jar` и `ZombieBuddy.jar` не входят в дистрибутив. Требуются Gradle 9.1.0 и ECJ 3.43.0; инструкции и SHA-256 находятся в [WORKSHOP_INSTALL.md](docs/WORKSHOP_INSTALL.md).
